# Event Run-of-Show Compiler — micro-launch preview

Give a structured event agenda, roles and cues; receive a master run-of-show,
role-specific cue sheets and explicit missing-owner/cue exceptions.

This preview is local, synthetic and read-only. It does not coordinate a live
event, send notifications, or replace an event-production system.

## Try the preview

Use the included demo input and compare the generated master schedule with the
role views and exception report.

## Signal

Open an issue with the label `local-preview` to request the preview or report a
reproducible limitation. Do not include private event data.
