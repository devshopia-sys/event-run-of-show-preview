# Turn a structured event agenda into a master run-of-show, role views, and exceptions

**Input:** agenda items, times, roles and cues.

**Output:** one master run-of-show, role views and a short exception list.

The preview is designed for review before distribution. It refuses to invent
owners or cues and marks missing information explicitly.

**CTA:** I want to try the local preview.

At publication, this CTA should point to the repository issue form. The local
package does not claim that a public issue endpoint is already active.
